# Answer Assistant · 自动答题助手

基于 Manifest V3 的 Edge 浏览器扩展，通过用户配置的 API 识别题目、生成答案、双模型独立复核，并在填写后读回页面状态。当前版本 **4.12.0**。始终不自动提交作业或考试。

## 功能

- 单模型答题，或两个模型各自独立作答；一致后填写，分歧及明确不确定的结果进入复审工作台。
- 按设置跳过已有答案，保留有效待复审记录并继续后续题。
- 人工确认候选答案后填写、验证，再移入已处理；页面已是所选答案时先核对并归档。
- 请求或解析失败会停止；重新开始会重试该题。旧版误存的请求失败不会作为有效人工复审跳过。
- 题目、原答案、课程与页面身份发生变化时停止，避免把迟到答案写到另一题。
- 图片与整题截图输入仅在平台结构和模型能力检查通过时使用。

## 安装

1. 下载并解压此仓库，或克隆到本地。
2. 打开 Edge 扩展管理页面，启用开发者模式，选择“加载解压缩的扩展”。
3. 选择包含 `manifest.json` 的仓库目录。
4. 在扩展设置中填写自己的 API Key 和模型配置，绑定当前作业的课程背景。
5. 打开已适配的答题页面开始运行。更新后重载扩展，并重新加载来源作业页以注入新脚本；先确认原答案已被平台保留。

API Key 保存在本机扩展设置中，请勿提交到仓库或分享包含配置的导出文件。题面与必要图片会随模型请求发送给配置的供应商；API 费用由用户自己的账户承担。正常流程使用 DeepSeek 与通义千问 API；不接入免费网页对话。已增加官方余额/免费额度与实际 Token 用量。可选第三轮复审尚未实现。

## 适配范围与限制

| 平台入口 | 当前范围 |
| --- | --- |
| 雨课堂 / 学堂在线 | 已实现的作业、试卷和逐题页面结构，按页面能力处理选项、判断、填空及已适配编辑器 |
| 学习通 | `mooc1.chaoxing.com/mooc-ans/mooc2/work/dowork` 作业入口及已适配题型 |
| 智慧树 AI 教学中心 | `hike-teaching-center.polymas.com/exam-hub/<课程>/stu/answer-homework`；单选、多选、对/错判断 |

不同入口和页面变体需要单独验证；这不代表全平台支持。未知题型、编辑器或无法可靠读取的题面会跳过或停止。平台页面可能自行保存，扩展仅在有明确证据时显示保存成功；本机草稿和页面验证均不代表平台已保存。模型一致也不等同于标准答案正确。插件不会点击提交按钮。

## 开发与验证

Node.js 24.5 或更新版本。普通合成单元测试无需安装依赖；Windows 本机组件检查使用自带 PowerShell/.NET 编译器，在其他系统跳过这些 Windows 检查：

```sh
npm test
```

此仓库包含可移植的合成单元测试，覆盖答案校验、双模型、状态恢复、复审持久化、平台身份等。内部完整发布检查另有隔离浏览器与独立安装包测试；真实课程采集、诊断、浏览器配置及历史评分材料不公开。单元测试通过不代表真实平台验收或模型正确率已验证。

## 4.11.3 变更

保持题目编号与题型的严格匹配，提示模型原样复制外层及内部答案的身份字段。失败诊断新增出错层、预期/实际身份、字段形态、模型来源及题号；刷新后可从历史诊断定位。不保存原始模型回复或隐藏思维链，不增加自动重试，也不自动改写不匹配的编号。

旧失败记录在覆盖模式下先退出待处理并保留审计，兼容早期索引摘要；接近详情容量上限时，迁移只更新索引状态，原始证据保留，仍可清理历史详情释放空间。此前缺失实际响应的身份错误无法据此反推具体字段，提示增强也不保证模型永不返回错误身份。

## 4.12.0 余额与用量

“用量”页显示 DeepSeek 官方余额（沿用已有 Key），以及 Qwen 中国站北京当前模型的官方免费 Token 余量、总量与到期时间。Qwen 余量不是阿里云人民币余额，官方数据可能延迟数分钟。原 API 答题流程保持不变；实际 usage 按模型统计本次任务/今日输入、输出和总 Token，失败或取消未返回 usage 时显示未确认。最近七天最多 2000 次尝试，截断及存储问题会提示统计不完整。

Qwen 模型 Key 无法直接读取控制台额度。可选连接流程：下载扩展随附的 `bridge/answer-assistant-quota-bridge.zip` → 解压 → 安装 Node.js 24.5+ → 在组件目录运行插件给出的安装命令 → 点击连接并允许本机权限 → 本人在阿里云官网授权 → 确认官网账号与答题 Key 归属一致。详细安装和卸载见 [本机组件说明](native/README.md)。不连接组件也能继续 API 答题和查看已返回的实际用量。

本机组件仅适配官方 CLI 必要只读协议，不安装完整 CLI、不创建 API Key、不读取已有浏览器或其他工具凭证。令牌由 Windows DPAPI CurrentUser 保护，不返回扩展。换 Key/授权会话会隐藏旧数据并要求重新关联；查询失败只保留同账号旧值与时间，不阻断答题。仅在没有答题任务时打开官网授权页。手动与用量页自动查询共享至少 60 秒间隔。

组件源码及双许可证已公开。Windows 上执行 `npm run package`（另需 Python 3 和 `py` 命令）可构造固定清单的双许可证内嵌组件包及扩展 ZIP；本地登录数据、配置和编译产物不入包。测试使用合成响应、临时凭证和隔离浏览器；真实安装、本人官方授权与实际账户额度仍需用户验收。始终不自动提交作业。
